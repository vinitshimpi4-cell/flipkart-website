# Flipkart Shopping App – Frontend Demo

Responsive marketplace-style shopping UI made with plain HTML, CSS and JavaScript.

## Features
- Product cards with sample product data
- Working **Add to cart** feature
- Cart drawer with live item count
- Increase/decrease quantity and remove items
- Automatic subtotal and total calculation
- Search, category filters and sorting
- Responsive desktop and mobile layout
- Demo checkout message (no payment processing)

## Run locally
Open `index.html` in a web browser. No build tools or dependencies required.

## Upload to GitHub
1. Extract this ZIP.
2. Upload `index.html`, `css/`, `js/`, and `README.md` directly into your repository root.
3. Commit the changes.
4. For GitHub Pages, go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/(root)`.
5. Wait for deployment, then open the Pages URL.

This is a frontend demonstration with sample data, not an official Flipkart application. Checkout is not connected to a payment gateway.
